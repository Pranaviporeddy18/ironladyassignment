
# Iron Lady Assignment

This repository contains multiple projects, and each project has its own specific README file. Please check the individual folders for the respective README files that provide detailed instructions and documentation for each project.

## Project Structure

* **/todoapplication-iron-lady**: A Todo Application that helps users manage tasks, with features like AI task suggestions, prioritization, and analytics.

  * Detailed README is available inside the **/todoapplication-iron-lady** directory.

Each project is isolated with its own setup instructions, dependencies, and functionality. You can navigate into the specific project folder to get more information.

## How to Use This Repository

1. Clone the repository:

   ```bash
   git clone https://github.com/Pranaviporeddy18/ironladyassignment.git
   cd ironladyassignment
   ```

2. Navigate to the project folder:

   * For the **Todo Application**, go to the `todoapplication-iron-lady` folder:

     ```bash
     cd todoapplication-iron-lady
     ```

3. Check the corresponding **README.md** inside each folder to get specific setup instructions for that project.
